Este documento responde a la observación de la evaluación de la Entrega 4, que pidió dejar por escrito cuál es el repositorio oficial del proyecto y explicar la denominación del sistema.

## 1. Repositorio oficial

El repositorio oficial y único del proyecto, sobre el que debe evaluarse la entrega final, es:

**https://github.com/charito20/ACERS_Sistema_de_Gestion_Agricola_con_IA**

Todo el trabajo del proyecto reside en este repositorio: la especificación de requisitos, el modelado, la matriz de trazabilidad, el producto mínimo viable, el componente empírico, el paquete de datos, la documentación ética, los materiales de defensa y las evidencias de autoría. El primer commit de este repositorio es del 29 de agosto de 2026.

## 2. Repositorio anterior (Entrega 3)

En la Entrega 3 (2A) el equipo declaró el repositorio:

**https://github.com/Roselyn15/Proyecto-IR---AgroMoreira---Sistema-de-Gesti-n-Agr-cola-con-IA-para-cultivos-de-verde-y-cacao-**

Ese repositorio corresponde a una etapa anterior del proyecto. El equipo consolidó todo el trabajo en un único repositorio, el declarado en la Sección 1, con el fin de tener una sola línea de historial, una única estructura de carpetas conforme a la guía y un único conjunto de identificadores persistentes. El repositorio anterior no se sigue actualizando y no debe usarse para la evaluación.

## 3. Denominación del proyecto

En la documentación del proyecto aparecen dos nombres. No corresponden a un cambio de nombre del sistema, sino a dos referencias distintas:

- **ACERS** es el nombre del **equipo** de trabajo, tal como figura en la guía de la asignatura. El repositorio se nombró a partir del equipo.
- **AgroMoreira** es el nombre del **sistema de software** que se especifica y se construye. Toma su nombre del cliente, **Agrícola Moreira**, la finca de policultivo de cacao y plátano verde para la que se desarrolla el sistema.

Es decir: el equipo ACERS desarrolla el sistema AgroMoreira para el cliente Agrícola Moreira. El equipo unificará esta nomenclatura en el README y en el ERS para evitar la ambigüedad detectada en la evaluación.
