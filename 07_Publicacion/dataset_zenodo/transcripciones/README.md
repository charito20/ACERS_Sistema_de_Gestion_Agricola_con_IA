# Transcripciones anonimizadas (JSON estructurado)

Carpeta de destino para el paquete Zenodo. Aqui se depositaran las
transcripciones anonimizadas en formato JSON estructurado, con el codigo del
participante, el rol, la fecha y el identificador de evidencia (EV-XX), sin
nombres propios. Se completan al momento de preparar el deposito en Zenodo.

Fuente: `02_Evidencias/Transcripciones/` (TXT) -> este paquete (JSON).
